# EzyPOS – Point of Sale Management System

**EzyPOS** is a Flutter-based Point of Sale (POS) application developed to help small businesses manage their daily sales and business operations through a digital platform.

The project integrates Firebase services and provides a range of business management modules, including product management, sales, inventory, purchases and reporting.

The application has been developed with Android, iOS and Web platforms in mind and has undergone practical testing with a small number of shops.

**Project Status:** Partially Functional | Under Development

---

## 1. Project Overview

EzyPOS aims to simplify everyday business operations by bringing essential point-of-sale and inventory management functions into one application.

The project focuses on providing a user-friendly interface, organized business records and accessible management tools for small retail businesses.

## 2. Key Features and Modules

The source code includes the following application modules:

- **Authentication:** User registration, login and password recovery.
- **Dashboard:** Business overview and navigation.
- **Product Management:** Adding, updating and managing products.
- **Sales Management:** Sales transactions and sales records.
- **Purchase Management:** Purchase records and supplier-related operations.
- **Inventory Management:** Stock tracking and product management.
- **Customer Management:** Customer records and information.
- **Expense Management:** Business expense records.
- **Financial Reporting:** Sales reports and profit/loss calculations.
- **Due Management:** Customer due calculations and records.
- **Discount Management:** Discounts and promotional codes.
- **Delivery Management:** Delivery address management.
- **Payment Management:** Payment-related options and configurations.
- **Barcode Scanning:** Barcode scanning functionality.
- **Document Generation:** PDF generation and document handling.
- **Printing:** Bluetooth thermal printing support.
- **Localization:** Multi-language interface support.

Feature availability may vary depending on the current implementation and platform.

## 8. Installation and Setup

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Git
- Appropriate Firebase project configuration

### Clone the Repository

```bash
git clone https://github.com/Jawharsayem/ezypos.git
```

### Navigate to the Project

```bash
cd ezypos
```

### Install Dependencies

```bash
flutter pub get
```

### Configure Firebase

Ensure the Firebase configuration files and platform settings are correctly configured for the intended development environment.

### Run the Application

```bash
flutter run
```

For platform-specific builds, refer to the official Flutter documentation:

https://docs.flutter.dev/
